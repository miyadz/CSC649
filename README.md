# CSC649 Setup Activity

## Description
A Python CLI program that prompts the user for a sentence, checks if the input is empty, and calculates both the word count and total character count (including spaces).

## How to Run
1. Open the project in PyCharm with Python 3.12 (`.venv`).
2. Run `main.py` using the PyCharm Run button or via the terminal:
