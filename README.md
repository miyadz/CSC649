# CSC649 Setup Activity

## Description
A Python CLI program that takes a sentence as input, checks that it is not empty, and calculates the word count and character counts (with and without whitespace).

## How to Run
1. Open the project in PyCharm with Python 3.12 (`.venv`).
2. Run `main.py` using the PyCharm Run button or via the terminal:
   ```bash
   python main.py
